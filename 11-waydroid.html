Sessão 📱 Waydroid (Android no Linux)
⚠️ O Waydroid requer GPU AMD ou Intel. Usuários com GPU Nvidia não podem usar esta sessão (o driver proprietário não expõe o Mesa necessário). Há um projeto experimental (waydroid-nvidia) que tenta contornar via proxy Vulkan, mas não é suportado pelo FOF.
O Waydroid roda o Android dentro de um container no Fedora. Esta sessão instala o Waydroid, inicializa o container com a imagem do Android, e oferece os extras mais pedidos (Google Play Store, tradução ARM, Magisk, Widevine).
🟢 Instalação Base

Waydroid (via COPR yanqiyu/waydroid)

Instala o Waydroid e o lzip (dependência do script de extras). Usamos o COPR yanqiyu/waydroid porque o pacote oficial está quebrado no Fedora 44 (Bug 2420131) e o COPR tem a versão funcional para Fedora 44/45.

Inicializar o Waydroid (uma vez só)

Baixa as imagens do Android (sistema ~1,2 GB + vendor ~190 MB) e inicializa o container. Usa a variante GAPPS (com Google Apps). Roda uma vez só — depois disso, use "Abrir Waydroid" para iniciar o container sempre que quiser.

⏳ Iniciando...0%

Abrir Waydroid (iniciar o container)

Abre a interface do Android. Inicia o container se ele não estiver rodando. O container precisa estar rodando para instalar extras (GApps, Magisk, etc.). Clique aqui uma vez antes de usar os extras.

Desinstalar Waydroid

Remove o Waydroid e todos os dados do container (imagens, apps Android instalados, configurações). Ação irreversível.

Preparar Ambiente de Extras

Clona o waydroid_script, cria um ambiente Python isolado (venv) e instala as dependências. Este passo é pré-requisito para todos os extras abaixo. Roda uma vez só.

⚠️ Requer que o Waydroid já esteja instalado, inicializado E com o container rodando (use "Abrir Waydroid" acima). Sem isso, os extras falham.

GApps (Google Play Store)

Instala os aplicativos Google, incluindo a Google Play Store, no container Android. Requer o Ambiente de Extras preparado e o container rodando.

Tradução ARM (libndk / libhoudini)

Permite rodar apps Android compilados para ARM em máquinas x86_64. libndk costuma ter melhor performance em CPUs AMD; libhoudini é a opção tradicional para Intel. Instale apenas uma das duas.

Suíte avançada para usuários Android. Fornece root e gerenciamento de módulos dentro do container. Requer o Ambiente de Extras preparado.

waydroid-helper (GUI Avançada)
