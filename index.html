📋 Sobre o Fedora Only Fans

O FOF é uma ferramenta open-source que automatiza as principais tarefas de configuração do Fedora Linux, desde a instalação de codecs e repositórios até a otimização do sistema e gerenciamento de kernels.

💾 Progresso salvo automaticamente no servidor local
🔄 Botões de reversão para desfazer alterações
📡 Logs em tempo real via Server-Sent Events
📊 Barras de progresso para acompanhar a execução
🛡️ Comandos validados e testados para o Fedora
🐧 Suporte para GNOME, KDE, XFCE e outros
