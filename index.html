Iniciar Configuração

Siga passo a passo pelas sessões de configuração do Fedora, na ordem certa — a ordem importa pro resultado final, então esta é a única forma de percorrê-las.

  • Sessões organizadas em ordem lógica
  • Navegação com botões Anterior/Próximo
  • Busca global com Ctrl+K

Manutenção

Tarefas do dia a dia que não dependem de ordem: gerenciar kernels, limpar arquivos temporários, ajustar o GRUB, atualizar ou desinstalar o FOF.

  • Gerenciamento de kernels instalados
  • Limpeza de arquivos temporários
  • Configuração do GRUB
  • Atualizar, desinstalar e ver changelog do FOF

📋 Sobre o Fedora Only Fans

O FOF é uma ferramenta open-source que automatiza as principais tarefas de configuração do Fedora Linux, desde a instalação de codecs e repositórios até a otimização do sistema e gerenciamento de kernels.

💾 Progresso de cada ação salvo automaticamente no servidor local
🔄 Estado de cada ação salvo automaticamente, sem depender de relatórios
📡 Logs em tempo real via Server-Sent Events
📊 Barras de progresso para acompanhar a execução
🔍 Busca global (Ctrl+K) para encontrar qualquer sessão ou botão
🐧 Suporte para GNOME, KDE, XFCE e outros
