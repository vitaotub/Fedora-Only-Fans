⚠️ Snapper não está configurado ou não está funcionando

O Snapper é a ferramenta que gerencia os snapshots, mas ele ainda não foi configurado para a raiz do sistema ou não está funcionando corretamente.

O que esta configuração vai fazer?

  • Instalar o Snapper (se necessário)
  • Configurar o GRUB para mostrar snapshots (10 segundos de timeout)
  • Criar a configuração root no Snapper
  • Ativar snapshots automáticos (horários, diários, etc.)
  • Criar a pasta /.snapshots para armazenar os snapshots

📖 O que são Snapshots Btrfs?

Snapshots são "fotos" do seu sistema em um determinado momento. Com o Btrfs, você pode criar snapshots instantâneos, ocupando pouco espaço, e restaurar o sistema para um estado anterior se algo der errado.

O Btrfs-Assistant é a ferramenta gráfica completa para isso, mas aqui você encontra as ações mais comuns de forma simplificada.

⚠️ Atenção: Todas as operações que modificam snapshots exigem autenticação de administrador.
